GoogleドライブのようにS3にファイルをアップロード、ダウンロードできるMacのネイティブアプリを作りたい

<アプリの技術スタック>
フロントはTauriで構築し、Rustでバックエンドを実装する。Rustのバックエンドは、AWS SDK for Rustを使用してS3と通信する。
フロントエンド部分はViteを使ってReact + TypeScript

<アプリ名>
S3 Drive App

<前提>
S3バケット、IAMユーザ（ロールも込み）は事前にAWS側で設定済みとする。
そのため、アプリからはS3バケットの指定、IAMユーザの入力を行う。

<デザイン>
デスクトップシェル：Tauri v2
コンポーネントライブラリ：shadcn/ui（TypeScript + Tailwind）
土台の部品ライブラリはBase UI

フォントを -apple-system 系のシステムフォントにする
prefers-color-scheme でダーク／ライトモードに追従する
ボタン等の上ではカーソルを矢印（cursor: default）にし、テキスト選択を必要な箇所に限る
タイトルバーを透過させる

<アプリ機能>
・ユーザ認証（Google認証）
・利用容量、リージョン、ストレージクラスの表示
・ストレージクラスの変更
・ファイル一覧表示、アップロード、ダウンロード、ファイル削除
・S3に関わるコスト表示
・ファイルのメタデータ表示（作成日、更新日、サイズなど）
・ファイルの検索機能（名前、拡張子、サイズなどでフィルタリング）
・フォルダ構造の表示と管理（フォルダ作成、削除、移動）
・ファイルのバージョン管理（バージョンの表示、復元、削除）

<CICD>
github Actionsを使用して、コードのビルド、テスト、デプロイを自動化する。Tauriのビルドプロセスも含める。
